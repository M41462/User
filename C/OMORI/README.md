# OMORI

A 2D exploration game inspired by OMORI, featuring character sprites, animations, collision detection, and interactive objects.

## How It Works

Raylib renders an 800×800 world. Control the OMORI character with arrow keys — the sprite changes direction based on movement. Collision detection prevents walking through walls and objects. Interact with doors and NPCs (including a cat). Features custom OMORI-themed fonts and atmospheric background music.

## Build

```bash
make
make run
```
